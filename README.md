# patient-no-show-prediction--A-ML-PROJECT-KNIME-
Machine learning project using KNIME to predict hospital patient no-shows, improving scheduling efficiency with Random Forest and SMOTE.

## Project Overview
This project uses machine learning in KNIME to predict whether patients are likely to miss hospital appointments.

## Tools Used
- KNIME Analytics Platform
- Decision Tree
- Random Forest
- SMOTE
- Healthcare appointment dataset

## Dataset
The dataset contains 110,527 hospital appointments, with about 20.2% recorded as no-shows.

## Key Findings
- Longer waiting time increases no-show risk.
- Younger patients had higher no-show rates than seniors.
- No-show rates varied by neighbourhood.
- Random Forest with SMOTE improved no-show detection.

## Model Performance
The improved Random Forest model achieved:
- Accuracy: 71.7%
- No-show recall: 69.5%
- Cohen’s Kappa: 0.435

## Conclusion
The model can support hospitals in identifying high-risk no-show patients and improving scheduling efficiency.
